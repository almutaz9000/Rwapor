# Development Archive

This directory preserves historical development material. It is not package runtime code, is excluded from package builds, and must not be used as an implementation source without validating it against the current public API and tests.

Current contents:

- `2026-05-production-cleanup/improvements/`: superseded review notes and implementation proposals.
- `2026-05-production-cleanup/project-snapshots-Savola/`: project-specific historical snapshot material.

Use production paths for active work:

- `R/`, `inst/`, `man/`, `tests/testthat/`, and `vignettes/` for package behavior.
- `dev-tools/scripts/` for maintained diagnostics and maintenance scripts.
- `agent-workflow/` for current task and issue state.

Historical files may be deleted only after their information has been incorporated into active documentation or a tracked decision record.
