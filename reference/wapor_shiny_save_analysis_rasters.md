# Save Analysis Rasters (Shiny Helper)

Save Analysis Rasters (Shiny Helper)

## Usage

``` r
wapor_shiny_save_analysis_rasters(
  results,
  folder,
  season_label,
  indicators,
  include_monthly = FALSE
)
```

## Arguments

- results:

  List of analysis results.

- folder:

  Path to output folder.

- season_label:

  Character label for the season.

- indicators:

  Character vector of indicators to save.

- include_monthly:

  Logical. Include monthly rasters and summaries.
