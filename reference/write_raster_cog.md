# Write a Cloud-Optimized GeoTIFF

Write a Cloud-Optimized GeoTIFF

## Usage

``` r
write_raster_cog(r, path, ...)
```

## Arguments

- r:

  SpatRaster to write.

- path:

  Output path.

- ...:

  Passed to
  [`wapor_write_cog()`](https://almutaz9000.github.io/Rwapor/reference/wapor_write_cog.md).

## Value

`path`, invisibly.
