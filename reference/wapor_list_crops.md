# List Available Crop Profiles

Returns the names of all saved crop profiles in the FAO defaults
dataset.

## Usage

``` r
wapor_list_crops()
```

## Value

Character vector of crop names.

## Examples

``` r
wapor_list_crops()
#>  [1] "Winter Wheat" "Sorghum"      "Sugarbeet"    "Maize"        "Rice"        
#>  [6] "Cotton"       "Potato"       "Soybean"      "Sunflower"    "Barley"      
#> [11] "Alfalfa"      "Sugarcane"   
```
