# Plot a crop coefficient curve

Plot a crop coefficient curve

## Usage

``` r
wapor_plot_kc_curve(kc_daily, save = NULL, dpi = 300)
```

## Arguments

- kc_daily:

  Numeric vector of daily crop coefficient values.

- save:

  Optional output path.

- dpi:

  Resolution for saved output.

## Value

A ggplot object.
