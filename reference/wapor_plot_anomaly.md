# Plot a z-score anomaly raster

Plot a z-score anomaly raster

## Usage

``` r
wapor_plot_anomaly(zscore_array, save = NULL, dpi = 300)
```

## Arguments

- zscore_array:

  SpatRaster or numeric matrix of z-score values.

- save:

  Optional output path.

- dpi:

  Resolution for saved output.

## Value

A ggplot object.
