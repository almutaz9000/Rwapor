# Build a stack of monthly relative ET (AETI / ETc)

Build a stack of monthly relative ET (AETI / ETc)

## Usage

``` r
wapor_relative_et_stack(result)
```

## Arguments

- result:

  A seasonal-analysis result with `monthly_aeti` and `monthly_etc`, or a
  list with those names.

## Value

A SpatRaster of AETI_t / ETc_t.
