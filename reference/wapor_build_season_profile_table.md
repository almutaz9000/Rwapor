# Build a table of unique season profiles (start/end combinations)

Build a table of unique season profiles (start/end combinations)

## Usage

``` r
wapor_build_season_profile_table(
  crop_mask,
  start_raster,
  end_raster,
  class_values
)
```

## Arguments

- crop_mask:

  SpatRaster.

- start_raster:

  SpatRaster.

- end_raster:

  SpatRaster.

- class_values:

  Integer vector.

## Value

data.frame of profiles.
