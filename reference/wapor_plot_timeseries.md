# Plot a grouped time series

Plot a grouped time series

## Usage

``` r
wapor_plot_timeseries(data, value, group = NULL, save = NULL, dpi = 300)
```

## Arguments

- data:

  Data frame containing the time and value columns.

- value:

  Character name of the numeric value column.

- group:

  Optional character name of a grouping column.

- save:

  Optional output path.

- dpi:

  Resolution for saved output.

## Value

A ggplot object.
